# BC 사이클 6-가 — 붉은실 예고 예측기 설계 (기존 녹화로 가능)

## 발견
로그에서 **붉은 해골 증가(피격) 14회** 확인 (241~430초).
붉은실은 피격 1.32초 전에 예고 궤적이 화면에 나타남 (스킬 데이터).

## 예고 예측기 설계 (표준 ML: 이진 분류)
- **Positive**: 피격 순간 -1.32초(40프레임) 프레임 — 예고 궤적이 화면에 있었을 것
- **Negative**: 그 외 보스전 프레임 (피격 없이 안전하게 지나간 구간)
- **관측**: 붉은 픽셀 7레인 분포 (사이클 3에서 검증된 특징) + WARN 플래그
- **목표**: "1.32초 후 이 레인에 실이 나온다"를 예측 → 회피 행동의 직접 신호

## 기대 효과
이 예측기가 작동하면:
1. 관측 브리지의 "미구현 필드"(붉은실 예고)가 채워짐
2. BC 관측에 예고 정보 추가 → 사이클 7에서 전문가 행동 예측력 재측정
3. v7과 전문가의 격차를 메우는 실질 경로

## 제약
- Positive 14개뿐 (피격이 드묾) — 클래스 균형: negative 오버샘플/undersample 필요
- "예고가 보였는데 피격 안 한" 프레임도 negative로 분류될 수 있음 (라벨 노이즈)
  → 반복 녹화로 데이터 축적이 정확도 상한을 결정
